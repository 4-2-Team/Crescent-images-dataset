# Crescent Moon Images

This repository contains a collection of crescent Moon images used for lunar imaging and computer vision research.

## Purpose

The images in this repository are intended for research and experimentation involving:

* Crescent Moon detection
* Lunar image processing
* Image quality analysis
* Machine learning dataset preparation
* Computer vision experiments

## Data Source

The images were collected from the **NASA Scientific Visualization Studio (SVS)**:

https://svs.gsfc.nasa.gov/

NASA Scientific Visualization Studio provides scientific visualizations, imagery, animations, and other multimedia related to NASA missions and scientific research.
